# «Готово до уроку»

Сайт-вітрина авторських навчальних матеріалів для початкової школи. Проєкт створено на Next.js, TypeScript і Tailwind CSS та налаштовано як повністю статичний сайт для безкоштовного розміщення на Netlify.

Каталог автоматично імпортується з публічної бібліотеки авторки на «Всеосвіті»:

https://vseosvita.ua/user/id9131/library

## Швидкий запуск

Потрібен Node.js 22.9 або новіший.

```bash
npm install
npm run dev
```

Локальна адреса з’явиться в терміналі. Зазвичай це `http://localhost:3000`.

## Основні команди

```bash
npm run import-materials
npm run validate
npm run validate:images
npm run build
npm run test:export
npm run serve:export
npm run test:browser
```

- `import-materials` проходить усі доступні сторінки публічної бібліотеки, оновлює `data/materials.json` і зберігає локальні WebP-обкладинки.
- `validate` перевіряє структуру каталогу, унікальність адрес і обов’язкові поля.
- `validate:images` перевіряє всі локальні та публічні зображення і створює звіт `test-results/image-report.json`.
- `build` створює готовий статичний сайт у папці `out`.
- `test:export` перевіряє всі прямі сторінки матеріалів, службові сторінки та файли SEO.
- `test:browser` перевіряє сайт у Chrome на комп’ютерному й мобільному розмірах екрана. Перед ним потрібно запустити `npm run serve:export`.

## Де редагувати каталог

Єдине джерело даних каталогу — `data/materials.json`. Кожний запис містить назву, описи, клас, предмет, тип і формат матеріалу, зображення, статус доступу, посилання на конкретну сторінку «Всеосвіти» та інші публічні відомості.

Найпростіший спосіб додати нові матеріали з бібліотеки:

```bash
npm run import-materials
npm run build
```

Скрипт сам знайде нові публічні позиції, створить адреси сторінок і збереже доступні обкладинки. Платні PDF, PPTX, DOCX та архіви не копіюються на сайт.

Щоб додати матеріал вручну:

1. Скопіюй наявний запис у `data/materials.json`.
2. Заміни `id`, `slug`, `title`, описи, категорію, клас, предмет, формат і теги.
3. У `vseosvitaUrl` встав конкретне посилання на матеріал.
4. Для безкоштовного матеріалу встанови `"isFree": true`, для платного — `false`.
5. Якщо частина публічних даних ще невідома, залиш поле порожнім і встанови `"needsReview": true`. Не додавай припущень.
6. Запусти `npm run validate` і `npm run build`.

`slug` має бути унікальним, написаним латиницею, цифрами й дефісами. Після збірки матеріал автоматично з’явиться у каталозі, пошуку, фільтрах, sitemap і на власній сторінці `/materials/[slug]/`.

## Як замінити зображення

Локальні прев’ю зберігаються так:

```text
public/materials/[slug]/cover.webp
```

Поклади новий оптимізований WebP-файл у папку матеріалу та вкажи у записі:

```json
{
  "coverImage": "/materials/[slug]/cover.webp",
  "images": [
    "/materials/[slug]/cover.webp"
  ],
  "ogImage": "/materials/[slug]/cover.webp",
  "previewStatus": "local"
}
```

До масиву `images` можна додати інші дозволені локальні прев’ю або стабільні публічні URL. Готові прев’ю з «Всеосвіти» не перемальовуються й не отримують другий водяний знак. Якщо створюється нове фірмове резервне прев’ю, на ньому потрібен точний водяний знак `gotovo_do_uroku` у правому нижньому кутку.

Два бренд-еталони лежать у `public/brand/logo.png` і `public/brand/hero-banner.png`. Вони використовуються без змін.

## Як змінити тексти й посилання

- Головна сторінка: `app/page.tsx` і компоненти у `components`.
- Сторінки «Про автора», «Як придбати» та «Контакти»: відповідні папки у `app`.
- Постійні адреси Telegram, «Всеосвіти», Facebook і сайту: `lib/site.ts`.
- Тексти окремих матеріалів: `data/materials.json`.
- Стилі: `app/globals.css`.

Сайт не приймає оплату. Кнопка платного матеріалу веде на конкретну сторінку зовнішньої платформи «Всеосвіта».

## Форма повідомлень

Форма на сторінці `/contacts/` підключена до Netlify Forms, має перевірку полів, згоду з політикою конфіденційності та honeypot-захист. Після публікації повідомлення з’являються у розділі **Forms** панелі Netlify.

## Аналітика й підтвердження Google

Скопіюй `.env.example` у `.env.local` для локальної роботи або додай потрібні значення в Netlify:

```text
NEXT_PUBLIC_GA_ID=
NEXT_PUBLIC_META_PIXEL_ID=
NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION=
```

Порожні значення безпечні: жодні вигадані ідентифікатори не підключаються.

## Публікація на Netlify

У репозиторії вже є `netlify.toml`:

- команда збірки — `npm run build`;
- папка публікації — `out`;
- Node.js — 24.14;
- NPM — 11.18.

Після під’єднання GitHub-репозиторію Netlify автоматично перебудовує сайт після кожного оновлення гілки `main`.

Для ручної перевірки перед публікацією:

```bash
npm install
npm run import-materials
npm run validate
npm run validate:images
npm run build
npm run test:export
```

## Як під’єднати власний домен

У Netlify відкрий сайт, далі **Domain management → Add a domain → Add a domain you already own**. Введи домен і виконай запропоновані налаштування DNS у свого реєстратора. Після підтвердження Netlify автоматично випустить HTTPS-сертифікат.

Код і структура сайту при цьому не змінюються. Після під’єднання домену потрібно лише замінити `SITE_URL` у `lib/site.ts` на нову канонічну адресу та повторно опублікувати сайт, щоб canonical, Open Graph і sitemap містили власний домен.

## Звіти першого імпорту

- `data/import-report.json` — кількість перевірених сторінок, матеріалів, карток, прев’ю та записів для ручного уточнення.
- `test-results/browser-report.json` — результати браузерної перевірки.
- `test-results/image-report.json` — результат суцільної перевірки зображень.

Папка `test-results` не публікується на сайті й не додається до GitHub; вона призначена для локального контролю.
